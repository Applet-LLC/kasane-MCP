# kasane-MCP を使いはじめる

日本語 | [English](GETTING-STARTED.en.md)

AI エージェントに「Caps Lock を左 Ctrl にして」と頼むと、kasane の設定ファイルを作ってくれる。そのための設定と、使い方の案内です。Claude Desktop を例にしています。

**このローカル MCP サーバーは、設定ファイルを作るのみです。** かさねエディタへの設定の反映は、ユーザーによる設定ファイルのインポートで実施できます。エージェントが作るのは、設定ファイル（`*.kasane.json`）だけで、キーボードへの適用は、エディタで、あなた自身が行います。

## 準備するもの

- kasane をインストールして、ライセンスを認証してあること。
- Node.js 18 以上。`npx` が使えるかは、ターミナルで `node -v` と `npx -v` を打って確かめます。
- AI エージェント。この文書では、Claude Desktop を扱います。

kasane は、既定の場所（`C:\Program Files\applet\kasane`）に入っていれば、そのまま見つかります。別の場所に入れたときは、後の設定例に `env` を足します（[kasane が見つからないとき](#kasane-が見つからないとき)）。

## Claude Desktop で使う

### 先に、開発者モードを有効にする

kasane-MCP のような、自分のパソコンで動く MCP サーバーを使うには、Claude Desktop の開発者モードを、先に有効にする必要があります。有効にしていないと、設定に「開発者」が出ません。

開発者モードの有効にしかたは、Claude Desktop の更新で変わることがあります。この文書には書かないので、Claude Desktop に、こう聞いてください。

> Claude Desktop を開発者モードにするにはどうすればよいですか？

案内された手順で、開発者モードを有効にしてから、次に進みます。

### 登録する

1. `claude_desktop_config.json` を開きます。Claude Desktop のメニューから「開発者」を選び、「アプリ設定ファイルを開く」を選択してください。フォルダー、または登録されているエディタで、`claude_desktop_config.json` が開きます。メニューの名前は、版によって違うことがあります。
2. 開いたファイルに、`mcpServers` の記述を足します。ファイルの場所は、`%APPDATA%\Claude\claude_desktop_config.json` です。Microsoft Store 版の Claude Desktop では、実際の場所が `%LOCALAPPDATA%\Packages\Claude_pzs8sxrjxfjjc\LocalCache\Roaming\Claude\` の下になります。ファイルの今の中身によって、足し方が違います。

   **ファイルが空、または `{ }` だけのとき**は、全体を次のようにします。

   ```json
   {
     "mcpServers": {
       "kasane": {
         "command": "npx",
         "args": ["-y", "kasane-mcp"]
       }
     }
   }
   ```

   **ほかの設定がすでにあって、`mcpServers` が無いとき**は、ファイルの一番最後の `}` の手前に、`"mcpServers": { ... }` を、ほかの項目と同じ階層で足します。このとき、今の最後の項目の後ろに、カンマ（`,`）を付けるのを忘れないでください。

   たとえば、ファイルの末尾が、次のようになっているとします（`"preferences"` の中身は省略しています。パスは、あなたのユーザー名のものです）。

   ```json
       },
     "coworkUserFilesPath": "C:\\Users\\（あなたのユーザー名）\\Claude"
   }
   ```

   この `"coworkUserFilesPath"` の行の最後に、カンマを足し、その下に `mcpServers` を続けます。足したあとの末尾は、次のようになります。

   ```json
       },
     "coworkUserFilesPath": "C:\\Users\\（あなたのユーザー名）\\Claude",
     "mcpServers": {
       "kasane": {
         "command": "npx",
         "args": ["-y", "kasane-mcp"]
       }
     }
   }
   ```

   最後の項目（`"mcpServers"`）の後ろには、カンマを付けません。`"preferences"` などの、ファイルの前のほうは、変えません。

   **すでに `mcpServers` があるとき**は、その `{ }` の中に、`"kasane": { ... }` の部分だけを足します。ほかのサーバーの定義の後ろにカンマを付けて、続けて書きます。

   ```json
   "mcpServers": {
     "（すでにあるサーバー）": { "command": "..." },
     "kasane": {
       "command": "npx",
       "args": ["-y", "kasane-mcp"]
     }
   }
   ```

   カンマの付け忘れや、括弧の足りなさがあると、Claude Desktop が設定を読めません。保存する前に、`{` と `}` の数が合っているか確かめてください。

3. 保存して、Claude Desktop を完全に終了し（ウィンドウを閉じるだけでなく、タスクトレイからも終了します）、起動し直します。
4. 起動し直した Claude Desktop では、登録した kasane が「プラグイン」として扱われます。新しい会話で、次のように頼むと、有効にできます。

   > プラグイン kasane-MCP を有効にしてください。

   有効になったら、次の「動作を確かめる」に進みます。

起動しないときは、`command` と `args` を、次の形に変えて試してください。

```json
"command": "cmd",
"args": ["/c", "npx", "-y", "kasane-mcp"]
```

### 動作を確かめる

kasane-MCP を有効にした会話で、こう頼みます。ツールの使用を許可するか聞かれたら、内容を見て許可してください。

> kasane の状態を教えて。

導入されているか、バージョン、接続中のキーボードの数が返ってくれば成功です。「UniqId が 00000000 になっている」と返ってきたときは、ライセンスの認証が済んでいない可能性があります。

## 設定を頼む

登録したあとの流れは、どのエージェントでも同じです。ここでは、3 つの頼み方を紹介します。

どの例でも、エージェントは、次の順に進めます。

1. 導入状況と、今のキーマップを確かめる。
2. 使うキーコードを探し、設定ファイルの中身を検証する。
3. 問題がなければ、`ドキュメント\kasane-mcp\` に、`*.kasane.json` を保存する。
4. 保存したファイルの場所と、エディタでの読み込み手順を、あなたに伝える。

この時点では、キーボードの動きは、何も変わっていません。

### 例 A: Caps Lock と左 Ctrl を入れ替える

> Caps Lock と左 Ctrl を入れ替える設定ファイルを作って。

JIS キーボードで、英数キーの位置にある Caps Lock が対象です。作られる設定は、[capslock-ctrl-swap.kasane.json](examples/capslock-ctrl-swap.kasane.json) と同じものです。

### 例 B: キーを押して、決まった文字列を打つ（キーの列を出力する）

> Ctrl+1 を押すと、「ありがとうございます」と打たれるようにして。

kasane の「マクロ」は、キーの列を順に打つ機能です。この例では、`a r i g a t o u g o z a i m a s u` のローマ字を打つマクロを作り、Ctrl+1 に割り当てます。作られる設定は、[ctrl1-macro.kasane.json](examples/ctrl1-macro.kasane.json) と同じものです。

- IME がオンのときに押すと、「ありがとうございます」が入力されます。確定は、Enter を押します。
- 1 つのマクロは、64 ステップまでです。キー 1 つで 2 ステップ使うので、打てるのは、およそ 32 キーまでです。長い文章は、入りません。
- マクロに入れられるのはキーコードだけです。日本語の文字そのものは、入れられません。この例はローマ字入力を前提にしています。かな入力で使っているときは、同じキーでも、別の文字が入ります。

### 例 C: Space を押しながら H J K L で矢印キー

> Space を押したまま H J K L を押すと、矢印キーとして動くようにして。

Space を押しっぱなしにしている間だけ、別のレイヤーに切り替わる設定です。短く押せば、普通の Space です。作られる設定は、[space-arrows.kasane.json](examples/space-arrows.kasane.json) と同じものです。速く打つと、意図せず長押しと判定されることがあります。そのときは、エディタの設定の「タイミング」タブで、判定方式を変えます。

## エディタで読み込んで、適用する

エージェントが保存したファイルを、kasane のエディタで読み込みます。

1. エディタを開きます。キーボードへ適用するには、管理者として起動している必要があります。
2. 画面の下の「インポート／エクスポート...」を押し、「インポート」タブを選びます。
3. 「ファイルを選ぶ...」で、エージェントが伝えたファイルを選びます。
4. 読み込み方で、**「追加」** を選びます。今の設定を残したまま、このファイルの内容だけを足します。**「置き換え」は、選んだ項目を作り直し、ファイルに無いキーを初期状態に戻します。** 設定全体を入れ替えるときだけ使ってください。
5. ファイルの中のキーボードを、接続中のキーボードに対応づけます（自動で割り当てられます）。
6. 「内容確認」を押して、結果を見ます。問題がなければ、「読み込む」を押します。
7. 最後に、「キーボードに適用(ON)」を押します。ここで初めて、キーボードの動きが変わります。

読み込む前に、念のため、今の設定を「エクスポート」で書き出しておくと、いつでも戻せます。

### 入力できなくなったとき

左右の Ctrl と左右の Shift（既定の組み合わせ）を、3 秒同時に押し続けてください。リマップが OFF になります。そのあと、エディタで設定を直します。詳しくは、kasane のマニュアルの「7. 緊急解除」にあります。エージェントに「入力できなくなった」と頼んでも、同じ手順を案内します。

## AI を使わずに、例のファイルを使う

この文書の例 A から C のファイルは、[docs/examples](examples/) にあります。ダウンロードして、上の手順で読み込めば、エージェントなしでも同じ設定になります。

## うまくいかないとき

### kasane が見つからないとき

kasane を既定の場所以外に入れたときは、登録の設定に `env` を足します。`KASANE_HOME` には、`manual` と `docs` のフォルダーがある、kasane のインストール先を書きます。

```json
"kasane": {
  "command": "npx",
  "args": ["-y", "kasane-mcp"],
  "env": { "KASANE_HOME": "D:\\Tools\\applet\\kasane" }
}
```

### ツールが一覧に出ないとき

- JSON の書き方を確かめます。カンマの付け忘れや、閉じ括弧の足りなさが、よくある原因です。
- `node -v` が 18 以上か確かめます。
- Claude Desktop は、完全に終了してから、起動し直します。
- 会社や学校のパソコンで、ローカルの MCP サーバーが制限されていることがあります。管理者に確認してください。

### 設定ファイルが保存されないとき

エージェントが「検証でエラーが見つかった」と返したときは、設定の中身に問題があります。エージェントが直して、もう一度保存します。保存先は、環境変数 `KASANE_MCP_OUTPUT_DIR` で変えられます。

## kasane-MCP が、できること・できないこと

- **できること**: kasane のマニュアルの検索、導入状況の確認、接続中のキーボードと今のキーマップの読み取り、キーコードの検索、設定ファイルの検証と保存。
- **しないこと**: キーボードの設定の変更、リマップの ON と OFF、ドライバへの書き込み。管理者権限も使いません。
- 反映は、いつも、エディタで、あなたが行います。
